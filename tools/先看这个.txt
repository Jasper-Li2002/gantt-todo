日历待办 · 甘特视图  v@VERSION@
====================================
免安装 · 不用装 .NET · 不用管理员权限 · 数据只存本机

────────────────────────────────────
1. 怎么运行
────────────────────────────────────
把整个文件夹解压到任意位置（建议 D:\Tools\TodoCalendar），
双击 TodoCalendar.exe 即可。

- 首次启动会慢 2~3 秒（要把内置的运行时解包一次），之后就快了。
- 想放桌面：右键 TodoCalendar.exe → 发送到 → 桌面快捷方式。
  注意别只把快捷方式拷来拷去，exe 本身要留在文件夹里。

────────────────────────────────────
2. 第一次打开可能遇到的两个提示
────────────────────────────────────
① Windows 蓝框「Windows 已保护你的电脑」
   → 点「更多信息」→「仍要运行」。
   原因：这个 exe 没有买代码签名证书，不是病毒。

② 杀毒软件拦截 / 报可疑
   → 加信任。单文件自解压程序（一个 exe 里塞了整套运行时）
     经常被启发式规则误报，属常见现象。

────────────────────────────────────
3. 数据存在哪 / 怎么备份
────────────────────────────────────
  %APPDATA%\TodoCalendar\
  ├─ todos.json        ← 你的全部待办
  ├─ todos.json.bak    ← 上一次写入前的自动备份
  └─ window-state.json ← 窗口位置

- 数据不跟着 exe 走：删掉程序不会丢数据，挪走文件夹数据也还在。
- 换电脑：先关掉程序，把上面这个 TodoCalendar 文件夹整个拷过去即可。
- 误删想找回：把 todos.json.bak 改名成 todos.json 再打开。

────────────────────────────────────
4. 三分钟上手
────────────────────────────────────
· 日历区：在格子上按住拖一段 = 建一个跨天任务；单击某天 = 建当天任务。
· 任务条：点一下打开编辑（改日期、优先级、进度都在里面）；
  条左侧的圆圈 = 打勾完成；鼠标悬停能看到完整信息。
· 左侧：切日历分组（全部 / 个人 / 工作 / 家庭）和标签筛选。
· 顶栏「📄 AI 日报」「📊 AI 周报」：
    弹窗里选日期 → 自动生成 → 「复制全文」粘到企业微信或邮件。
    日报 Ctrl+Shift+D，周报 Ctrl+Shift+W。
· 想让日报周报更像人写的（可选）：
    「⋯ → AI 设置」填一个大模型 API Key——DeepSeek / 通义千问 /
    Kimi / 智谱 都行。不填也能用，走本地规则版，只是文风偏机械。
    Key 用 Windows DPAPI 加密后存在本机，不会外传。
    配好 Key 之后，点顶栏的「AI 日报 / AI 周报」会直接进 AI 版页签。

────────────────────────────────────
4.5 关于「开机自动运行」（建议打开）
────────────────────────────────────
顶栏「⋯ → 开机自启」里可以打开。打开后：
· 开机自动在右下角托盘静默运行，不弹窗、不抢焦点；
· 关掉程序或重启电脑，该提醒的事项照样提醒；
· 不需要管理员权限（写在当前用户的注册表里）。
不想要就再点一下取消勾选。

────────────────────────────────────
4.6 到期待办提醒是怎么响的
────────────────────────────────────
程序在托盘里跑着（含开机自启）时，每天会给一次提醒气泡，内容随剩余时间变：
  · 已过半程 · 第 4/7 天      跨天任务过了大半还没动，只提醒这一次
  · 明天截止 · 剩 1 天 15 小时
  · 今天截止 · 剩 6 小时
  · 逾期 2 天（黄色警告图标）
跨天任务后面会带「进度 N%」。逾期超 3 天的只在末尾汇总一项，不逐条刷屏。
点一下气泡即可打开窗口。

────────────────────────────────────
5. 快捷键与小习惯
────────────────────────────────────
  Alt + Ctrl + T    任何地方唤起窗口
  Ctrl + Shift + D  生成日报
  Ctrl + Shift + W  生成周报
  F6                窗口置顶／取消置顶
  F5                刷新界面      F12  调试面板（一般用不到）

  ⚠ 点窗口右上角 × 只是收进右下角托盘，程序还在跑（这样才能定时提醒、
    才能用快捷键唤起）。真要退出：托盘图标右键 → 退出。

────────────────────────────────────
6. 万一提示「缺少 WebView2 运行时」
────────────────────────────────────
Win11 和正常更新的 Win10 都自带，一般不会遇到。
真遇到了，装一个就行（免费，微软官方）：
https://developer.microsoft.com/microsoft-edge/webview2/
选「Evergreen Bootstrapper」下载安装，装完重开程序。

────────────────────────────────────
7. 一点说明
────────────────────────────────────
· 这是单机版：所有数据都在你自己电脑上，不联网、不上传。
  只有你主动点「用 AI 改写」时，会把当次生成的文字发给你自己填的
  那个大模型服务商。
· 更新版本：直接用新的 TodoCalendar.exe 覆盖旧的即可，数据不受影响。
· 有任何用得别扭的地方直接跟我说，功能都还能改。

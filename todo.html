    AI 设置用于把事实清单改写成日报 / 周报

    Key 用 Windows DPAPI 按当前用户加密保存，不写入 todos.json、不进入浏览器缓存。

    怎么填？三步

    1. 上面选厂商，base_url 与 model 会自动带出，不用改。
    2. 去厂商控制台复制 API Key（DeepSeek：platform.deepseek.com → API keys；通义：阿里云百炼控制台；Kimi：platform.moonshot.cn；智谱：open.bigmodel.cn）。
    3. 粘贴到上面 → 点「测试连接」看到连接成功 → 点「保存」。

    不想粘贴？用系统环境变量

    程序会依次读这些变量：DEEPSEEK_API_KEY DASHSCOPE_API_KEY MOONSHOT_API_KEY ZHIPUAI_API_KEY。 点「检测环境变量」，检测到就能一键导入。
    注意：改完系统环境变量必须重启本程序才读得到（进程只认启动那一刻的环境）。

    安全与边界

    1. Key 加密后存在 %APPDATA%\TodoCalendar\settings.dat，只有当前 Windows 用户能解。
    2. Key 只经由程序本体发出请求，页面脚本拿不到明文，也不会写进 todos.json。
    3. 生成时只发送任务标题、日期、状态；备注默认不发，勾选「包含备注」才会带。
    4. 断网、额度用尽或超时，会自动回落到规则版，不会让你拿不到内容。
